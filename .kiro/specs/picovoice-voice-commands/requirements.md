# Requirements Document

## Introduction

This feature integrates Picovoice voice command recognition into the Android application, enabling users to control the app and launch specific conversations using custom voice commands. The system operates in two modes: in-app commands for session control, and background service commands for launching the app with specific conversation threads.

## Glossary

- **Picovoice Porcupine**: The wake word detection engine from Picovoice integrated into the application
- **PorcupineService**: Android Foreground Service that continuously listens for wake words using Porcupine
- **Wake Word**: A custom voice trigger phrase that activates a specific action (e.g., launching a conversation)
- **System Wake Word**: Built-in wake words (start/stop/koniec) that control app behavior, always available
- **Custom Wake Word**: User-created wake words for launching specific conversations, imported as .ppn files
- **Wake Word Model File**: A .ppn file generated by Picovoice Console containing the trained wake word model
- **Picovoice Console**: Web-based tool at console.picovoice.ai for creating custom wake word models
- **Wake Word Status**: Visual indicator showing whether a custom wake word has a valid .ppn file loaded (green) or needs import (gray/red)
- **Foreground Service**: Android service with persistent notification that runs continuously to listen for wake words
- **Thread Association**: The 1:1 mapping between a user wake word and a specific conversation thread
- **Activation Sound**: Audio feedback played when a wake word successfully triggers an action
- **Session Pause**: Temporary suspension of the active voice conversation (equivalent to mic button toggle)
- **PorcupineManager**: Picovoice SDK component that manages wake word detection lifecycle
- **Access Key**: Picovoice API key required to initialize Porcupine engine

## Requirements

### Requirement 1

**User Story:** As a user, I want to control my voice session using voice commands, so that I can pause/resume or exit without touching the screen

#### Acceptance Criteria

1. WHEN THE user speaks "start" or "stop" wake word, THE PorcupineService SHALL pause or resume the active voice session
2. WHEN THE user speaks "koniec" wake word, THE PorcupineService SHALL terminate the application completely
3. THE PorcupineService SHALL process system wake words with the same effect as manual UI interactions
4. WHILE THE application is in foreground, THE PorcupineService SHALL recognize system wake words within 500 milliseconds
5. THE PorcupineService SHALL provide visual feedback when a system wake word is recognized
6. THE PorcupineService SHALL operate as a Foreground Service with persistent notification

### Requirement 2

**User Story:** As a user, I want to create custom wake words for my conversations, so that I can launch them hands-free using voice commands

#### Acceptance Criteria

1. THE Picovoice Porcupine SHALL allow users to add new custom wake words by providing a wake word name
2. WHEN THE user adds a custom wake word, THE Picovoice Porcupine SHALL display detailed instructions for creating the wake word in Picovoice Console
3. THE Picovoice Porcupine SHALL provide a direct link to Picovoice Console (https://console.picovoice.ai) in the instructions
4. THE Picovoice Porcupine SHALL display step-by-step instructions including: account creation, wake word creation, language selection (Polish), and .ppn file download
5. THE Picovoice Porcupine SHALL provide a file picker to import the downloaded .ppn file
6. WHEN THE user imports a valid .ppn file, THE Picovoice Porcupine SHALL display the wake word with green status indicator
7. WHEN THE wake word has no .ppn file imported, THE Picovoice Porcupine SHALL display gray or red status indicator
8. THE Picovoice Porcupine SHALL persist imported .ppn files in app storage across app restarts
9. THE Picovoice Porcupine SHALL allow users to re-import .ppn files for existing wake words
10. THE Picovoice Porcupine SHALL allow users to delete custom wake words and their associated .ppn files
11. THE Picovoice Porcupine SHALL validate imported .ppn files before accepting them

### Requirement 3

**User Story:** As a user, I want to associate my custom wake words with specific conversation threads, so that speaking a wake word launches the correct conversation

#### Acceptance Criteria

1. THE Picovoice Porcupine SHALL allow users to assign one custom wake word to one conversation thread
2. THE Picovoice Porcupine SHALL only show custom wake words with valid .ppn files (green status) in the thread assignment interface
3. WHEN THE user assigns a wake word to a thread, THE Picovoice Porcupine SHALL remove that wake word from the available wake words list for other threads
4. THE Picovoice Porcupine SHALL prevent assigning the same wake word to multiple threads
5. WHEN THE user unassigns a wake word from a thread, THE Picovoice Porcupine SHALL return that wake word to the available wake words list
6. THE Picovoice Porcupine SHALL display assigned wake words in the thread configuration interface
7. THE Picovoice Porcupine SHALL persist wake word-thread associations across app restarts
8. THE Picovoice Porcupine SHALL load the associated .ppn file into PorcupineManager when a thread has an assigned wake word

### Requirement 4

**User Story:** As a user, I want the app to listen for my wake words in the background, so that I can launch conversations without opening the app first

#### Acceptance Criteria

1. THE PorcupineService SHALL continuously listen for system wake words (start/stop/koniec) and custom wake words when enabled
2. THE PorcupineService SHALL load all system wake word models and custom wake word .ppn files that are assigned to threads
3. WHEN THE PorcupineService recognizes a custom wake word, THE PorcupineService SHALL launch MainActivity with appropriate Intent
4. WHEN THE PorcupineService launches MainActivity, THE PorcupineService SHALL pass the associated thread ID through Intent extras
5. WHEN MainActivity receives a wake word Intent, MainActivity SHALL automatically start the associated conversation thread
6. WHEN THE PorcupineService recognizes "start" or "stop" wake word, THE PorcupineService SHALL toggle the microphone state in the active session
7. WHEN THE PorcupineService recognizes "koniec" wake word, THE PorcupineService SHALL terminate the application completely
8. THE PorcupineService SHALL play an activation sound after successfully recognizing any wake word
9. THE PorcupineService SHALL operate as a Foreground Service with persistent notification
10. THE PorcupineService SHALL respect Android battery optimization settings
11. WHEN THE user disables Picovoice, THE PorcupineService SHALL stop PorcupineManager and terminate
12. THE PorcupineService SHALL restart automatically after system boot when enabled

### Requirement 5

**User Story:** As a user, I want to configure Picovoice settings, so that I can enable/disable wake word detection and manage my custom wake words

#### Acceptance Criteria

1. THE Picovoice Porcupine SHALL provide a dedicated settings panel in the application settings screen
2. THE Picovoice Porcupine SHALL provide a toggle to enable or disable wake word detection
3. WHEN THE user enables Picovoice, THE Picovoice Porcupine SHALL start the PorcupineService
4. WHEN THE user disables Picovoice, THE Picovoice Porcupine SHALL stop the PorcupineService
5. THE Picovoice Porcupine SHALL display all custom wake words with their import status (green = .ppn imported, gray/red = not imported)
6. THE Picovoice Porcupine SHALL provide UI controls to add new custom wake words, import .ppn files, and delete custom wake words
7. THE Picovoice Porcupine SHALL display system wake words (start/stop/koniec) as always available and built-in
8. THE Picovoice Porcupine SHALL provide a field to enter and save the Picovoice Access Key
9. THE Picovoice Porcupine SHALL provide a sensitivity slider (0.0-1.0) to adjust wake word detection sensitivity
10. THE Picovoice Porcupine SHALL display instructions and link to Picovoice Console when user adds a new custom wake word

### Requirement 6

**User Story:** As a user, I want audio feedback when wake words are recognized, so that I know the system is responding to my voice

#### Acceptance Criteria

1. WHEN THE PorcupineService recognizes a wake word, THE PorcupineService SHALL play an activation sound within 200 milliseconds
2. THE PorcupineService SHALL use distinct sounds for system wake words versus user wake words
3. THE PorcupineService SHALL play the activation sound at system notification volume level
4. THE PorcupineService SHALL allow users to enable or disable activation sounds in settings
5. WHEN THE PorcupineService launches a conversation, THE PorcupineService SHALL play an extended activation sound to indicate listening state

### Requirement 7

**User Story:** As a user, I want the wake word detection system to work reliably, so that my wake words are recognized accurately

#### Acceptance Criteria

1. THE Picovoice Porcupine SHALL achieve a minimum 90% recognition accuracy for trained wake words
2. THE Picovoice Porcupine SHALL handle background noise without false positives
3. WHEN THE Picovoice Porcupine fails to recognize a wake word, THE Picovoice Porcupine SHALL not trigger any action
4. THE Picovoice Porcupine SHALL process wake words within 500 milliseconds of speech completion
5. THE PorcupineService SHALL request microphone permission before enabling wake word detection
6. WHEN THE microphone permission is denied, THE PorcupineService SHALL disable wake word functionality and display an error message
7. THE PorcupineService SHALL handle PorcupineManager initialization errors gracefully
8. WHEN THE Picovoice Access Key is invalid, THE PorcupineService SHALL display an error message and prevent service start

### Requirement 8

**User Story:** As a user, I want clear instructions on how to create wake words in Picovoice Console, so that I can successfully import them into the app

#### Acceptance Criteria

1. WHEN THE user adds a new custom wake word, THE Picovoice Porcupine SHALL display a dialog with step-by-step instructions
2. THE Picovoice Porcupine SHALL include the following steps in the instructions: create Picovoice account, navigate to Porcupine section, create new wake word, select Polish language, download .ppn file
3. THE Picovoice Porcupine SHALL provide a clickable link to https://console.picovoice.ai that opens in external browser
4. THE Picovoice Porcupine SHALL provide a button to open file picker for importing the .ppn file
5. THE Picovoice Porcupine SHALL display the instructions in Polish language
6. THE Picovoice Porcupine SHALL allow users to view instructions again for existing wake words that don't have .ppn files imported
7. THE Picovoice Porcupine SHALL include tips for choosing good wake words (multi-syllable, unique pronunciation, avoid common words)

### Requirement 9

**User Story:** As a user, I want to see which wake words are available for assignment, so that I can efficiently manage my wake word-thread associations

#### Acceptance Criteria

1. THE Picovoice Porcupine SHALL display only custom wake words with valid .ppn files (green status) in the thread assignment interface
2. THE Picovoice Porcupine SHALL hide custom wake words that are already assigned to other threads
3. THE Picovoice Porcupine SHALL display the assigned wake word name in the thread configuration
4. THE Picovoice Porcupine SHALL provide a clear action to unassign a wake word from a thread
5. WHEN THE user views available wake words, THE Picovoice Porcupine SHALL indicate which wake words have .ppn files imported versus not imported
6. THE Picovoice Porcupine SHALL NOT show system wake words (start/stop/koniec) in the thread assignment interface as they are reserved for app control
